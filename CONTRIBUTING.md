# Contributing to Ducky

We're building Ducky in public. We welcome code contributions and bug fixes. Level contributions are welcome when a maintainer has requested them. Before starting a larger change, open an issue so we can agree on its scope.

The build, run and test commands are in the [README](README.md).

## Making a contribution

1. Read the [Code of Conduct](CODE_OF_CONDUCT.md), [code licence](LICENSE), [asset licence](ASSETS-LICENSE.md) and [trademark rules](TRADEMARKS.md).
2. For a bug report, describe what happened, what you expected, and how to reproduce it. Include your browser and device type when relevant.
3. Make a focused change on a branch. Forks must rename the game and replace the Ducky assets under the trademark rules.
4. Open a pull request with a short explanation and the checks you ran. For a visible change, include a screenshot or a short recording without personal information.
5. Sign the CLA once, then work through review with a maintainer.

## Signing the CLA

Every contributor must sign the [individual contributor licence agreement](CLA.md) once before a pull request can merge. Read it before signing. It is currently a draft pending review by counsel. Maintainers must complete that review before accepting contributions under it.

Once the workflow is on the default branch, CLA Assistant Lite will ask new contributors to post this exact comment on their pull request:

> I have read the CLA Document and I hereby sign the CLA

The signature is recorded on the `signatures` branch and reused for later pull requests under the same agreement. Maintainers must verify that every contributor has signed before merging. Material changes to the agreement require a new signature version and renewed consent.

Sign with a GitHub handle that does not reveal a real person's name. The signature record is public and includes your handle, account ID, comment ID, pull request number, repository ID and timestamp. Do not put a legal name, personal email address, private path or other private details in repository files or signing comments. Arrange any private paperwork with the company through a confirmed company contact.

## Code and assets

The MIT licence covers code only: src, scripts, config and tests. Ducky characters, names, story, dialogue, models, textures, images, animation and audio are covered by the asset licence.

Contributed assets become available for Maxwell Industries LLC to use, change, distribute, sublicense and relicense under the CLA. You keep copyright unless you separately choose the optional asset assignment. Signing the CLA alone does not transfer ownership.

Submit only work you have the right to contribute. Identify any third-party material and its licence in the pull request, and obtain a maintainer's agreement before adding it. Do not include secrets or personal information.
